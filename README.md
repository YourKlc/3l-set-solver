# Q区套装毕业词条求解器

冒险岛 Q区套装毕业词条最优搭配求解器。6 个部位各选 1 件、每件 3 条词条，按目标词条求最优组合。

内置一套默认搭配「五职业」；想用别的目标，就在「毕业词条」页点「＋ 新增搭配」，可以存任意多套，各自起名字、写备注、改词条条数，在目标卡上方的标签页随时切换，用不上的可删掉。支持库存导入导出。

「求解器」页的「加一件装备」里带识别：点「识别游戏窗口」展开，再点「开始共享」选游戏窗口（选择器默认停在「窗口」这一页，游戏要窗口化运行）。共享期间会一直识别你划过的每一件装备，按装备名自动判断部位、录入并去重，直到点「停止」；也可以在画面上框一块浮窗区域让识别更快。词条按整词匹配，`Critical Damage`、`Dimensional Leap` 这类全称都能认。不方便共享窗口时，拖入或粘贴装备截图也能识别。

界面随系统深浅色自动切换。直接用浏览器打开 `index.html` 即可离线使用，求解与编辑功能都不需要联网。
