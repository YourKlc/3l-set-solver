# Q区套装毕业词条求解器

冒险岛 Q区套装毕业词条最优搭配求解器。6 个部位各选 1 件、每件 3 条词条，按目标词条求最优组合。

内置一套默认搭配「五职业」；想用别的目标，就在「毕业词条」页点「＋ 新增搭配」，可以存任意多套，各自起名字、写备注、改词条条数，在目标卡上方的标签页随时切换，用不上的可删掉。支持库存导入导出。

「识别录入」页可以共享游戏窗口，把鼠标停在装备上，页面自己读出装备名和 3 条词条，按装备名判断部位并入库，不用手动选部位（第一次用需要联网加载识别引擎）；点「开始识别」时窗口选择器会默认停在「窗口」这一页。不方便共享窗口时，也可以拖入或粘贴装备截图来识别。

界面随系统深浅色自动切换。直接用浏览器打开 `index.html` 即可离线使用，求解与编辑功能都不需要联网。
